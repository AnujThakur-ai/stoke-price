# NEPSE Stock Price Analysis

A collection of historical Nepal Stock Exchange (NEPSE) ticker data, analysis notebooks, and MACD backtesting workbooks.

## Contents

- `stock_price_prediction.ipynb` and `stoke_price-NEPSE.ipynb` — notebook-based stock data analysis and prediction experiments.
- `*.csv` — historical data files organized by ticker symbol.
- `NEPSE_MACD_Backtest_2015_2026.xlsx` — backtest workbook on the default `master` branch.

## Branches

The default branch is `master`. The `buy-sell-1`, `buy-sell-2`, and `buy-sell-3` branches contain alternative trading experiments and reports.

```bash
git switch buy-sell-1
```

Open a notebook in Jupyter or VS Code and review its cells for dependencies and assumptions before running it. Historical results do not predict future returns; this project is for learning and is not investment advice.
